## architectural boundary

An architectural boundary in software engineering is the line or barrier that separates different parts of a software system to keep them independent of each other.
Book Clean Architecture, boundaries are designed to prevent business logic from depending on technical details, such as databases, user interfaces, or third-party frameworks.

### 4. idempotent

An idempotent operation is an action that produces the same result whether you do it once or many times

> Turning on a light switch: Pressing "on" once turns the light on, and pressing it again keeps it on.Setting a value: Setting a user's age to 25 leaves them at 25 no matter how many times you run the command.
> HTTP Methods (REST APIs):GET reads data without changing anything.PUT replaces a resource completely.DELETE removes a resource, and repeating it leaves the resource gone
